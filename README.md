# Zap downloads

Public installers and signed update feeds for Zap are published here.
Application source is maintained separately.

## Windows

When a release is available, download **Zap-windows-x64-Setup.exe** from
[Releases](https://github.com/ChromaBeast/Zap-releases/releases).
After installation, open **Settings → App updates** to choose manual updates,
startup notifications, or automatic startup installation.

Update metadata is authenticated with an application-pinned Ed25519 key.
Windows publisher signing is separate; unsigned installers may show a Windows
unknown-publisher warning.

No installers have been published yet. macOS builds are not available yet.
